Description:

Unofficial native PS Vita adaptation using Five Nights at Freddy's Android game data. Includes nights 1–6, Custom Night, saving, phone audio and subtitles, and local Extras. Update 2 adds three control layouts, perspective on camera feeds, radar portraits and faster menu startup. Playable game data is prepared separately. Requires local preparation from the exact supported application-data revision documented on GitHub. Not a general Android/Clickteam emulator and not affiliated with the original authors. AI edge fidelity, perspective and device performance have documented limitations.

Installation note:

Install the VPK, run the Windows/Python Data Tool against an owned supported APK, and copy the generated fnaf1 folder to ux0:data/. Keep progress.sav/progress.bak when upgrading. The downloader must not fetch or redistribute original game files.
